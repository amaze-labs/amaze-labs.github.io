IPMaze

02 · ~/amaze-labs/mazedns● available

MazeDNS

A filtering DNS resolver in the spirit of Pi-hole and AdGuard Home, built for more than one site.

  • One control plane, DNS agents close to your clients
  • Agents keep resolving if the control plane is down
  • Blocklists, rewrites, local zones, split-horizon
  • DoH, DoT, DNSSEC, OIDC and Prometheus

03 · ~/amaze-labs/mazeregistryui● available

MazeRegistryUI

A server-rendered web UI for your OCI and Docker registries, light enough for a phone.

  • Several registries one tab apart
  • Layers, multi-arch indexes, labels, raw manifest
  • One binary, one config file, runs air-gapped
  • The browser never talks to the registry

04 · ~/amaze-labs/mazecd● available

MazeCD

A mobile-first PWA that watches all your Argo CD instances from one screen.

  • Installs on your phone, updates itself
  • Resource tree, pod logs and git diff
  • The Argo CD token decides what you can do
  • Tokens never reach your device

MazeAMT

A web UI for out-of-band management of Intel AMT (vPro) PCs, remote desktop included.

~/amaze-labs/README.md● ai-assisted

We build with AI, and we say so.

We're IT graduates, not professional developers. By day one of us works in cybersecurity and the other as a DevOps / platform engineer: that's where our sense of what a homelab needs comes from.

We write these tools with AI coding assistants. AI helps us move faster; it doesn't make the decisions. Every change is reviewed, run in our own labs first, and read with a security mindset.

If something doesn't look right, open an issue.
